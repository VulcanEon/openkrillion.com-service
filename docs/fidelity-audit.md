# 逐屏对照与优化记录 · 2026-10-17

对照站：[krillion.io](https://krillion.io/)；实现：[openkrillion.com](https://openkrillion.com/)。

使用相同浏览器、1440×1000 桌面视口，以及 390×844 手机视口。记录首页、开始过渡、七题答题/下潜/落点、超时、上浮、结算首屏和滚动内容。原站截图和公开客户端包只用于本地研究，未放入 MIT 仓库。

## 主要差异与处理

| 屏幕/阶段 | 第一版差异 | 本次优化 | 仍存在的差异 |
| --- | --- | --- | --- |
| 首页 | 菜单和右侧按钮过于靠中；标题间距偏大；船形和天空偏灰 | 对齐舞台边距、海面位置、按钮高度、标题/副标题间距；增加逐字浮动；调整船、天空和云层 | OpenKrillion 品牌比原标题更长；云和船为独立绘制 |
| 手机首页 | 标题偏小；底部导航高度不一致；云/太阳位置不同 | 调整标题字号、底部两行导航、云和太阳相对海面的坐标 | 导航使用本站已实现的日志/指南/练习功能，未伪装成尚未实现的原站付费内容 |
| 开始/每题预览 | 输入框提前出现；世界画面没有完整镜头切换 | 预览时只显示倒计时提示；题卡延迟弹入、提交后约 0.65 秒退场；镜头约 2.2 秒过渡，预览总计 3 秒 | 原站镜头末段有轻微跟随余量，截图位置会随取帧时间变化 |
| 桌面答题 | 题卡横向居中位置、字号、输入区位置不同 | 题卡左偏 24px，40px 字号；输入区宽 600px；舞台底部位置一致 | 随机粒子、鱼的位置不同；深度注释答题时淡显，下潜时提亮 |
| 手机答题 | 题卡过宽；输入区和 HUD 进入动画不足；海草稀疏 | 题卡左 12px、右 62px；补齐进入动画、云层、侧边海草；短视口时重新计算镜头 | 海草和像素纹理仍为独立素材 |
| 输入/纠错/拒绝 | 缺少打字气泡；拒绝反馈和提交音色不同 | 增加输入/提交气泡、拒绝震动与提示；校准提交和拒绝音效 | 别名和容错匹配由本站独立实现 |
| 倒计时 | 只有圆环；从最后 5 秒开始提示 | 增加旋转雷达扫线、最后 3 秒加速、输入框/进度条变红、双脉冲警示 | 浏览器/设备的输出音量会影响听感 |
| Plankton 下潜/落点 | 用阶梯跳动代替连续下潜；落点是实心卡片 | 3.4 秒连续浮沉、漂移、气泡；落点改为透明徽章/文字 | 气泡和虾的具体轮廓不同 |
| Too Clever | 没有对应的完整特殊反馈 | 增加橙色鱼群穿场、角色晕转与小落点音 | 本日公开题库没有这一档，未拿原站本日七题做端到端对照 |
| Schooler | 缺少围绕答案的小鱼 | 3 秒运动与鱼群/气泡反馈 | 鱼为本站独立 SVG |
| Rare | 仅有普通粒子 | 3.4 秒运动、墨云、红色闪光与震动 | 墨云的随机形状不同 |
| Deep Cut | 没有跟随答案的聚光遮罩 | 4.3 秒运动、随答案移动的黑暗聚光、较重落点声 | 深海岩壁纹理不同 |
| One in a Krillion | 金色反馈即时发生；缺少环绕角色、延迟计分 | 4.6 秒下潜；小虾环绕；约 1 秒后金化、分数滚动、角色栖停与金色呼吸光 | 金色虾为本站重绘，非原站精灵图 |
| 第七题超时 | 红色警示可能残留到结算页 | 修正状态退出；空答案落点和漏答图标；仍按服务器截止时间判定 | 原站内部校验规则不完全可见 |
| 上浮 | 等上浮结束才出现结算 | 结算立即显示，海底背景在其下继续缓动上浮；按深度限制在约 2.5–9 秒 | 原站背景图片与本站程序背景不同 |
| 结算首屏 | 内容宽 600px；分数按档位上色；旧 HUD 透出 | 内容收窄至 448px；80px 白色总分、青色深度；隐藏旧 HUD；保留金色伙伴在面板上方；手机标题避让菜单按钮 | 标题为 OpenKrillion；练习模式明确标记 |
| 潜水日志/评级 | 180px 小图；方点；没有完整深度刻度 | 240px 日志、0/25/50/75/100 刻度、稀有度图标、分段落点和错落入场；评级增加图标 | 图标美术不是原图 |
| 分布/百分位 | 柱状图，且无数据时布局折叠 | 真实本站数据足够时显示平滑密度曲线；不足时保持图表空间和本人分数坐标 | 不复制原站玩家数据、不伪造曲线或百分位 |
| 声音 | 开始声偏高；倒计时单响；每档音色和衰减不同 | 独立 Web Audio 实现按原站事件的频率、滤波、音量包络和时序校准；补充高通噪声、重低音与错落琶音 | 随机噪声的逐样本波形不同；设备和音频实现也会影响听感 |

## 音效逐事件差异

以下是合成器的标称参数，采用独立实现。频率/滤波/包络可以客观对照；并未声称随机噪声或不同设备上的听感逐样本相同。

| 事件 | 第一版 | 本次校准 |
| --- | --- | --- |
| 开始/继续下潜 | 440→880Hz 及 880→220Hz，高音偏突出 | 110→48Hz 低音约 1.2 秒；784/523Hz 错落三角波；低通噪声由 2000Hz 扫到 240Hz |
| 提交 | 两段变频三角波/正弦波 | 1150Hz 正弦短音，约 0.16 秒 |
| 拒绝 | 180→65Hz 三角波，约 0.25 秒 | 150→62Hz 正弦约 0.36 秒，加 420Hz 低通噪声 |
| 穿过稀有度线 | 700→1350Hz | 780→1560Hz 三角波，约 0.07 秒 |
| 下沉持续声 | 1050→100Hz，约 0.9 秒 | 1150Hz 短持续音、300→60Hz 下扫；1.3 秒的低通噪声由 1400Hz 扫到 180Hz |
| 小落点 | Plankton 为 290→220Hz | 140→70Hz，约 0.25 秒，加短低频噪声；Too Clever 也使用小落点声 |
| 中/大落点 | Schooler、Rare、Deep Cut 使用不同上行旋律 | 共用 80→45Hz 重音、约 0.7 秒低通噪声，以及延迟 0.15 秒的 523Hz 三角波 |
| Krillion | 正弦琶音与低音即时叠加 | 60→40Hz 低音；784/988/1175/1568Hz 三角波以 0.13 秒间隔进入；补充带高通的微弱噪声 |
| 超时 | 简短下扫和低通噪声 | 220→52Hz 约 0.7 秒，叠加延迟 0.05 秒的低通噪声 |
| 倒计时 | 最后 5 秒的单次短响 | 最后 3 秒；每次 880Hz 双脉冲，第二次延迟约 120ms |
| 上浮 | 110→720Hz 与固定低通噪声 | 80→600Hz 约 1.5 秒，噪声低通从 300Hz 向 3000Hz 打开 |
| 点击伙伴 | 两个固定方向的滑音 | 随机轻微变调的 260→720Hz 上滑音，加极短带通噪声 |

## 验收与边界

- 10 项 Node/SQLite 测试通过；私有与公开目录分别完成构建、SEO/公开配置检查。
- 本地及部署后的桌面/手机完整七题、拒绝/纠错、暂停恢复、结果回顾、分享、刷新恢复、中文 AI 问题。
- 390×480 短视口下，题卡位于 HUD 下方、输入区上方。
- 15 个音效事件通过 OfflineAudioContext 渲染 WAV，检查可听输出、无削波、结尾衰减、静音和倒计时双脉冲间隔。
- 线上单独验证金化时序：落点约 100ms 时为 185 分且未染金；延迟后为 285 分且已金化，下一题继续保留。
- 最终部署版本：`fea6d7e7-7ff3-46c1-9080-e85ccbaca6f9`。
- 保留服务端计时、D1/R2、统计接入、可展开指南、原 Footer 和四份 AI 文档。

这是对可观察体验的尽量对齐，不能宣称像素、随机动画或音频样本完全相同。原站的精灵图/背景包没有被直接放入公开 MIT 代码。
